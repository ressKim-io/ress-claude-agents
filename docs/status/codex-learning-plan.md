## 아직 확인할 사항

- 별도 학습 프로젝트 이름·경로와 Codex 등록 완료 여부. 사용자가 등록할 예정이며 이 대화에서 프로젝트나 새 채팅을 생성하지 않음.
- OrbStack 설치·실행 상태와 버전, 학습 범위에 맞는 클러스터 구성 방식. Linux PC 사양 확인은 필요해질 때 진행.
- CKA 공식 시험 환경·제약을 확인하고, 평소 학습과 별도로 시험 환경 적응 연습을 포함할지 결정.
- 실습 전용 클러스터에서 에이전트가 수행할 작업과 사용자 직접 실습의 경계.
- 고정 주차별 일정 대신 이해·재현 여부에 따른 진도 기준. 응시 준비도와 할인·접수 조건은 실제 응시 검토 시 확인.
- 자격증 정보·문제 풀이 사이트의 첫 기능과 대상 시험, 공개 전 검증 기준, Go·Rust 및 Kubernetes 학습 연계 범위.
- Obsidian 내 사이트용 콘텐츠 폴더와 문서 형식, 검토 상태 및 사이트 이관 기준.
- 시범 후 재현 과정의 힌트·검증 방식과 실습 환경 초기화 범위. 환경 준비·초기화의 구체적인 실행 권한은 구현 계획에서 확정.
- Go 및 Rust 학습 수준과 세부 자산 선정은 각 후속 단계에서 확인. 첫 단계 범위에는 포함하지 않음.
- 기존 skills·agents의 재사용 범위, 전역 연결 방식과 Claude Code 호환성 검증 방법.

개인 실습 전용이라는 답변만으로 모든 클러스터 변경·삭제가 승인된 것으로 해석하지 않는다.
기존 운영 규칙의 변경이나 실습 환경 예외는 별도로 범위를 확정한다.

## 계획 수립 절차

1. 환경과 학습 방식에 관한 질문에 답을 받아 요구사항을 확정한다.
2. 관련 기존 자산을 읽기 전용으로 조사한다.
3. 변경 파일 목록, 적용 순서, 영향 범위와 검증 기준을 제시한다.
4. 3개 파일 이상 수정하는 변경은 사용자 승인 후 시작한다.
